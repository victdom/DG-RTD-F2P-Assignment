## Executive Summary
This repository contains the practical annex for the Business Analyst assignment. It demonstrates a structured approach to eliciting user needs, mapping a conceptual data pipeline, evaluating AI governance risks, and performing exploratory data analysis on research grant metadata.

## Repository Structure
* `README.md`: Overview of the assignment, approach, and repository contents.
* `F2P_Data_Exploration_Demo.ipynb`: Jupyter Notebook demonstrating basic data loading, metadata filtering, and semantic keyword analysis on simulated Horizon Europe grant reports.

## Key Approach & Workflow
1. **User Needs Elicitation:** Engaging policy teams to define key evidence requirements.
2. **FAIR Data Curation:** Standardizing metadata tags (Findable, Accessible, Interoperable, Reusable).
3. **AI & Portfolio Analysis:** Prototyping text summarization and keyword tagging with strict source attribution.
4. **Knowledge Sharing:** Publishing user guides and dashboards via the F2P Intranet.
